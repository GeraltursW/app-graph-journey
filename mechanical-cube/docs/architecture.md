# 结构与 AI 控制架构

## 机械坐标系

- X：移动头沿横梁左右移动。
- Y：龙门架沿 BOX 两侧导轨前后移动。
- Z：触笔相对移动头垂直升降。

手机固定器定义屏幕平面。相机和触笔之间需要固定外参偏移；相机检测到的屏幕像素 `(u, v)` 通过屏幕四角标定转换为机械平面坐标 `(x, y)`，触笔随后移动到 `(x, y, z_safe)`，再下降到点击高度 `z_tap`。

## 控制闭环

```text
页面稳定
  → 下视摄像头拍照
  → AI 识别目标控件与置信度
  → 像素坐标映射为机械坐标
  → 轨迹规划与安全高度检查
  → Y/X 定位
  → Z 轴单次点击
  → 触笔抬升
  → 再次拍照
  → AI 验证页面状态
```

建议真实系统为每一步记录时间戳、页面截图、模型输出、目标坐标、机械反馈和验证结果，便于复现失败用例。
