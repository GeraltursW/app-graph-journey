# GitHub 同步范围

从 v1.12.0 开始，只上传关键交付要素：

- `../videos/application-knowledge-graph-with-mechanical-replay.mp4`：最新正式成片，覆盖同一路径。
- 对应 SRT、ASS、STEP 提示。
- 支撑当前画面的源码、配置与构建脚本。
- 新增或改变口播所需的 MP3、WAV、词级时间及缓存签名，保证其他电脑可离线重建。
- 当前时间轴、验收记录、README、HANDOFF 和媒体校验清单。

本地 `output/` 保存预览、渲染帧、干净中间片和混音文件，不上传。每次不新增大体积的历史成片副本；历史版本通过 Git 标签查看。仓库已有历史模型与源素材继续保留，未经明确要求不删除、不改写历史。

生成视频后，先完整解码并检查字幕、STEP、语速和修改处，再明确选择文件提交。不要对整个工作区执行无差别暂存。
